# Canyon Clash

A 3D hyper-casual crowd-runner built with **Three.js**, wrapped as a native iOS app with
**Capacitor**. Steer a squad through `×2` gates to grow the crowd, out-gun the crimson horde,
and shatter a golden scorpion boss into a rain of coins. Each boss cleared lets you pick a
roguelite **upgrade** (Rapid Fire, Power Cell, Piercing Rounds, Twin Cannons, Energy Shield,
Reinforcements) while the difficulty ramps every level.

## Play online (free, no install)

Live on GitHub Pages: **https://andrewmacon91.github.io/canyon-clash/**
It's an installable **PWA** — on a phone, open in the browser → Share → **Add to Home Screen**
for a full-screen, offline-capable app icon (no App Store needed).

## Play it locally (Windows, no build needed)

Open `www/index.html` in a browser, or serve the folder:

```bash
npx serve www
```

Everything is **offline** — Three.js and the fonts are bundled.

## Project layout

```
www/                 the game for the native app (index.html + three.min.js + fonts)
docs/                the web/PWA build served by GitHub Pages (game + manifest + sw.js + privacy.html)
ios/                 native iOS project (generated by Capacitor)
assets/              icon.svg + generated icon/splash PNGs
capacitor.config.json
.github/workflows/   GitHub Actions: build on a macOS runner -> TestFlight
scripts/             asset + PWA icon generators
CHECKLIST.md         step-by-step App Store submission (no Mac needed)
```

> `www/` (native app) and `docs/` (web/PWA) share the same game. If you edit the game, copy the
> changes into both, or re-copy `www/index.html` → `docs/index.html` and keep the PWA `<head>` tags.

## Rebuild the iOS assets after editing the game

```bash
npx cap sync ios
npx capacitor-assets generate --ios   # only if the icon changed
```

## Shipping to the App Store

See **[CHECKLIST.md](CHECKLIST.md)**. Short version: push to GitHub → GitHub Actions builds on a
macOS runner → TestFlight → submit. No Mac required.

## Controls

Drag / move left & right (also `A`/`D` and `←`/`→`). **AUTO** button plays a hands-free demo
run — handy for screen-recording an ad.
